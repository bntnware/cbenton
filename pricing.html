Project Pricing & Engagements

Pricing is project-based and scoped by system complexity, asset families, variable-unit count, data prep, production logic, and handoff needs.

Focused Project

For tightly scoped systems with clear outcomes.

Campaign System

For multi-asset launches requiring coordinated visual logic.

Serialized / Variable Edition System

For systems where many related units share rules but vary in content.

Publication / Document System

For repeatable document/page frameworks with production consistency.

Workflow Integration / Consulting

For teams needing reusable production frameworks and implementation support.

Selective Small Projects

Accepted when the project still benefits from systems-based structure.

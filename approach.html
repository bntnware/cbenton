Approach

1. Define the project family

Frame the problem around a project system instead of isolated artifacts.

2. Set fixed elements and variables

Identify what stays constant and what can change safely across outputs.

3. Build production logic

Specify print/layout/data requirements so outputs are repeatable and auditable.

4. Deliver family outputs

Generate coherent project members: campaign assets, edition units, publication pages, or integration-ready components.

5. Extend or hand off

Provide a reusable framework for future additions, not one-time artwork dead ends.

BITSTREAM PROJECT

A one-sided, 52-unit playing-card population. Every unit shares a page architecture while carrying its own BITSTREAM configuration. Print production is organized as four units per panel; the website separates the imposed pages into 52 independent PNGs.

View all 52 units

One architecture, 52 configurations.

The project is the complete population—not any single named image. Across the deck, name typography, playing-card identity, cube states, line fields, color constructions, images and vector modules occupy a shared modular structure while changing from unit to unit.

One side is the complete object.

This project has no front/back pairing. Each published PNG is one complete, one-sided unit. Together the 52 units reveal how the common architecture holds while the internal configuration changes.

Project register

  • Population: 52 units
  • Sides: 1 per unit
  • Production: 4 units per panel
  • Panels: 13
  • Website: 52 unit-specific PNGs

01 / UNIT

A complete one-sided configuration.

The web image preserves the unit as a single surface at a detailed viewing scale. It is not paired with a reverse and it is not presented as an isolated project.

02 / PRODUCTION LOGIC

Four units per panel.

The source is imposed across 13 four-unit production panels. Web extraction reverses that imposition for viewing while preserving panel order: units 01–04 come from panel 01, units 05–08 from panel 02, and so on through unit 52 on panel 13.

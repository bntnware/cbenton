BOOTYZ — edition series

System type: Serialized / Edition System

Project intro

A family of related prints that explore color variation within a repeatable layout and captioning system.

The system

Rules

  • Color-variable palettes applied across a stable layout.
  • Consistent crop and captioning to preserve series identity.

Inputs

  • Base artwork files for each color variant.
  • Metadata for captioning and edition labeling.

Variable elements

  • Color tone
  • Paper treatment or finish

Fixed elements

  • Type lockup and caption placement
  • Margins and crop guides

How the system scales

New variants are created by switching the color palette and image variant while maintaining a single production pipeline for exporting print-ready files.

Outputs

Posters, front/back print variants, proof sheets, and digital presentation tiles for web galleries.

What changes from unit to unit

Primary differences are color palette and surface treatment; the underlying layout, captioning rules, and edition labeling remain constant to communicate series kinship.

Production architecture

  • Tools: raster assets and print setup for consistent color handling.
  • Automation/code: export scripts to produce print-ready PDFs and proof sheets.
  • Print constraints: multi-up sheets and cut marks considered in layout exports.

What the system makes possible

A cohesive edition structure that enables collectible presentation, consistent production, and efficient generation of new variants without reworking the layout logic.

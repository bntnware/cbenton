Object / two-sided / expandable

I’M COOL

An ambiguous ticket-like object developed into a framework for personal, agency and institutional identities.

The object came first.

Front and back connect through recurring language, registration, symbolic fields and identifiers. The original ambiguity leaves room for new contexts without losing the object’s identity.

Integration.

Names, colors, data and affiliations enter the structure while the two-sided architecture remains fixed.

Object register

  • Form: two-sided ticket-like object
  • Origin: ambiguous
  • Method: iterative and rule-based
  • Range: individual, agency and institution
  • Output: single objects and serialized editions

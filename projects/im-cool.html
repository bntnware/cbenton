I'M COOL — front/back systems

System type: Campaign System

Project intro

Coordinated front/back pieces that register across formats and scales, designed to be produced as a family with consistent provenance and layout logic.

The system

Rules

  • Registration and alignment rules for front/back continuity.
  • Consistent captioning and edition labeling to indicate provenance.

Inputs

  • Artwork files for front and back variants.
  • Metadata for captions and edition identifiers.

Variable elements

  • Color choice
  • Layout variant (but maintaining core grid)

Fixed elements

  • Logo bracket and type scale
  • Grid-based margins and caption placement

How the system scales

New variants are produced by swapping artwork and color while keeping layout, captioning, and provenance marks consistent. This allows both single prints and larger serialized runs to be generated without redesigning the core structure.

Outputs

Front/back prints, butted spreads, proof sheets, and web presentation tiles. Exports include print-ready PDFs with registration marks and color-managed files for production.

What changes from unit to unit

Primary changes are color and minor layout variants; systemic cues like logo bracket, caption placement, and edition marks remain stable so units read cohesively as a family.

Production architecture

  • Tools: raster assets and layout scripts to assemble front/back pairs.
  • Automation/code: templating for captions and edition labels.
  • Print constraints: attention to front/back registration, color separations, and multi-up imposition for efficient printing.

What the system makes possible

An efficient, repeatable production method for coordinated artifacts that read as a coherent campaign across print and digital channels, enabling selective editions and consistent public presentation.

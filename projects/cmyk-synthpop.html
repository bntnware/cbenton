Project / 32-unit population / front + back

CMYK SYNTHPOP

A deterministic population joining color-field letter structures to four-channel synthesizer control states. Print production is organized as four units per panel; the website separates those panels into 32 exact unit-specific front/back pairs.

View all 32 unit pairs

The field becomes an instrument.

Each front uses a dense rectilinear field in which letter structures emerge through CMYK-weighted cells, contrast and local color behavior. The field remains systematic while every unit establishes a distinct visual state.

The back exposes the controls.

The reverse organizes cyan, magenta, yellow and black as parallel synthesis channels. Oscillator and envelope families, frequency, offset, fine control, range, filtering and field behavior make the unit readable as a configured instrument rather than a decorative color variation.

Project register

  • Population: 32 units
  • Production: 4 units per panel
  • Website: 32 unit-specific PNG pairs
  • Pairing: front field / back synthesizer
  • Channels: cyan, magenta, yellow, black
  • Field selector: SAME / OPP / OFF / 50 / ON
01 / REGISTERED PAIR

One unit, two linked surfaces.

The front and back are published together for every unit. The top image records the field state; the lower image records the corresponding CMYK synthesis configuration.

02 / PRODUCTION LOGIC

Four units per panel.

The source edition is imposed in eight four-unit groups across paired front and back panels. Web extraction reverses that imposition for viewing: each of the 32 units receives its own pair without losing its original front/back registration.
